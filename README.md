# Customer Shopping Trends Dashboard

## Project Overview

This project presents an interactive dashboard for analyzing
customer shopping behavior and purchase patterns.

The dashboard was developed using Python, Pandas, Plotly, and Dash.

## Business Question

What factors influence customer purchasing behavior?

## Dataset

The dataset contains 3,900 customer shopping records and 19 variables,
including:

- Age
- Gender
- Category
- Item Purchased
- Purchase Amount
- Season
- Review Rating
- Subscription Status
- Discount Applied
- Previous Purchases
- Payment Method

## Dashboard Visualizations

The dashboard contains six different visualization types:

1. Bar Chart – Total Purchase Amount by Category
2. Line Chart – Purchase Amount Across Seasons
3. Scatter Plot – Age vs Purchase Amount
4. Histogram – Distribution of Purchase Amount
5. Heatmap – Correlation Between Customer Variables
6. Box Plot – Purchase Amount Distribution by Category

## Interactive Features

The dashboard provides:
https://customer-shopping-trends-dashboard-1.onrender.com
- Category filtering
- Gender filtering
- Subscription filtering
- Discount filtering
- Interactive hover information
- Zoom and pan
- Interactive chart legends
- Dynamic KPI cards

## Key Insights

- Purchase values vary across product categories.
- Purchase amounts differ across seasons.
- Age and purchase amount show a weak linear relationship.
- Customer behavior can be explored using multiple interactive filters.
